## Your task
Find every file in this repository that may be affected by the changes above.
A file is "affected" if:
  - it imports, instantiates, or calls a changed class or function
  - it calls a changed method and may behave differently due to the change
  - it depends on a data structure whose schema or contract changed
  - it is a test covering changed behaviour that may need updating

## Strategy
Choose your strategy based on file status:

**For [MODIFIED] files** — other files likely already import them.
Search for their class/function names to find direct callers.

**For [ADDED] files** — they are brand new, so no existing code imports them yet.
Do NOT waste steps searching for their class names — those searches will return nothing.
Instead, immediately focus on indirect impact:
  1. Identify what existing entities, repositories, or services they use.
  2. Search for other files that also use those same resources.
  3. Look for shared mutable state — same entity fields being written by multiple services.

**General rules:**
- You may call multiple tools in a single step when the searches are independent.
- If 3 or more searches in a row return no results, stop searching and call done().
- Do NOT call read_file on the changed files listed below — their content is already shown above.
- Prefer broad searches first, then read specific files to confirm a match.

Constraints:
  - Skip: .venv, node_modules, vendor, dist, __pycache__, binary files.
  - Do NOT include the changed files themselves in the impact list: {excluded_files}
  - Call done() as your last action.
