## Your task
Find every file in this repository that may be affected by the changes above.
A file is "affected" if:
  - it imports, instantiates, or calls a changed class or function
  - it calls a changed method and may behave differently due to the change
  - it depends on a data structure whose schema or contract changed
  - it is a test covering changed behaviour that may need updating
  - it is documentation describing the changed interface

## Strategy
1. Read BEFORE/AFTER code carefully — understand what semantically changed, not just what lines changed.
2. Search for references to changed symbol names, types, and field names.
3. Use read_file to confirm a match is a real dependency, not a comment or coincidence.
4. Follow one level of indirection: if a caller's tests may be affected, include them.
5. Stop when you have covered the obvious paths. Do not recurse infinitely.
